# Tanzeeli — app prototype (installable web app)

Static site, no build step. Open on a phone, then Share → Add to Home Screen (iPhone)
or ⋮ → Install app / Add to Home screen (Android) to launch it full-screen.

Deploy to Vercel from this folder:

    npx vercel --prod

Choose your account, create a new project (e.g. `tanzeeli-app`), accept the defaults.
